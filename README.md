# Libroteca - Certificación de Skillnest
## Descripción del Proyecto

**Libroteca** Es una página web que se utiliza para rentar libros de manera online, así como BlockBuster en su época pero sin internet, utilizando imágenes, secciones y botones para mayor eficiencia y flexibilidad.

Esta es una prueba para probar mis capacidades y conocimientos en Front-end, Utilizando HTML, CSS y JavaScript para recrear una página casi a la perfección solo basandome en una imagen e instrucciones básicas para poder realizar las funciones en JavaScript.

## Tecnologías y Herramientas Utilizadas

El desarrollo de esta certificación se llevó a cabo utilizando las siguientes tecnologías y herramientas estándar de la industria:

* **HTML5:** Estructuración semántica de la página (`<header>`, `<nav>`, `<main>`, `<img>`, entre otros).

* **CSS3:** Estilizado modular y maquetación visual (ubicado en `static/css/style.css`).

* **JavaScript (ES6):** Manipulación del DOM y lógica interactiva para la selección de libros y manejo de funciones para botones (ubicado en `static/js/script.js`).

* **Entorno de Desarrollo:** Visual Studio Code / Editor de código web.

## Instrucciones de Ejecución

1. **Clonar o descargar** el repositorio o los archivos del proyecto en un directorio local.

2. Mantener la estructura de carpetas indicada (`static/css`, `static/js`, `static/images`).

3. Abrir el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
